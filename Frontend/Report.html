🦋 Thyroid Tests
ℹ️ TSH (Thyroid Stimulating Hormone) — normal range: 0.4 to 4.0 mIU/L
Report mein kya dhundhein:
• TSH — "Thyroid Stimulating Hormone" likhaa hoga. Normal: 0.4-4.0
• T3 — "Triiodothyronine". Normal: 2.3-4.2
• T4 — "Thyroxine". Normal: 0.8-1.8
Agar report mein "mIU/L" ya "ng/dL" likha ho toh wahi wali values yahan bharein.
🩸 Blood Tests (CBC)
ℹ️ Hemoglobin se anemia pata chalta hai — women ke liye normal: 12.0-16.0 g/dL
CBC (Complete Blood Count) report mein dhundhein:
• Hb / Hemoglobin — "g/dL" mein hoga. Women ke liye normal 12-16
• MCV — Red blood cells ki size. Normal: 80-100 fL
• Serum Ferritin — Iron store. Normal: 15-150 ng/mL
• TIBC — Total Iron Binding Capacity
Yeh values aksar "Haematology" section mein milti hain.
🌀 Hormone Tests (PCOS ke liye)
ℹ️ LH/FSH ratio aur testosterone PCOS diagnose karne mein help karte hain
Hormone Panel / Fertility Panel mein dhundhein:
• LH — Luteinizing Hormone (mIU/mL)
• FSH — Follicle Stimulating Hormone (mIU/mL)
• AMH — Anti-Mullerian Hormone (ng/mL)
• Testosterone — Total Testosterone (ng/dL)
• Prolactin — (ng/mL)
Yeh tests aksar gynecologist recommend karte hain.
